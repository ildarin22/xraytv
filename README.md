# Xray для LG webOS

Приложение для рутованного LG webOS ТВ: YouTube идёт через ваш сервер Xray (VLESS + Reality),
остальной трафик — напрямую. Экран показывает, работает ли прокси, и позволяет ввести подписку пультом.

> **Подписка — это пароль от сервера.** Кто знает ссылку, тот пользуется вашим сервером.
> В приложении нет ни подписки, ни ключа: без своей подписки оно ничего не делает.
> Если ссылка утекла, смените её на сервере.

## Что нужно

- ТВ с рутом через [rootmy.tv](https://rootmy.tv) и установленным им Homebrew Channel;
- ссылка подписки вашего сервера Xray, которая отдаёт ссылку `vless://` с Reality.

## Установка на ТВ

1. Homebrew Channel → настройки → **Add repository**, адрес каталога:
   `https://raw.githubusercontent.com/ildarin22/xraytv/main/repo.json`
2. В списке Homebrew Channel выберите **Xray** → **Install**.
3. Откройте **Xray** → **Ввести подписку**, введите ссылку экранной клавиатурой → **Сохранить**.
   Через несколько секунд экран покажет «Работает».

Дальше Xray запускается сам при включении ТВ, ключ обновляется по подписке кнопкой «Обновить ключ».

**Обновление:** карточка Xray в Homebrew Channel → **Update**. Подписка, ключ и автозапуск сохраняются;
новая версия Xray включится после «Выключить» → «Включить» на экране или после перезагрузки ТВ.

## Для разработчика

```sh
./build.sh                                            # dist/xraytv.app_<версия>_arm.ipk и манифест
node test/app.test.js && node test/mkconfig.test.js && node test/build.test.js   # проверки на ПК
TV_PASS=<пароль root> ./install.sh <IP ТВ> [<подписка>]                         # поставить с ПК по SSH
TV_IP=<IP ТВ> TV_PASS=<пароль root> XRAYTV_SUB=<подписка> test/tv-test.sh       # сценарии на ТВ
./release.sh                                          # выпуск версии из app/appinfo.json (нужен gh)
```

`test/tv-test.sh` на время прогона останавливает Xray на ТВ и в конце запускает снова.
Подробности устройства — в `GLOSSARY.md` и комментариях `app/xrayctl`.
