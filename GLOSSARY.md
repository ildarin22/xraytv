# Xray для ТВ

Приложение для рутованного LG webOS, которое ведёт YouTube через свой VPS по протоколу Xray.
Язык документов и экрана русский, имена файлов и команд английские.

## Language

**Подписка**:
Ссылка на VPS, по которой ТВ получает актуальный ключ. Секрет: кто знает ссылку, тот пользуется сервером.
_Avoid_: сабскрипшн, ссылка на сервер, конфиг

**Ключ**:
Разобранные параметры подключения к серверу, полученные из подписки. Меняется при смене IP или сервера.
_Avoid_: vless-ссылка, профиль, конфиг

**Пакет**:
Устанавливаемое приложение (ipk) с экраном, xrayctl и бинарником Xray. Не содержит ни подписки, ни ключа.
_Avoid_: сборка, билд, приложение (когда речь о файле)

**Папка данных**:
Место на ТВ, где живут подписка, ключ и флаг «выключено». Переживает переустановку пакета.
_Avoid_: конфиг-папка, настройки

**Каталог**:
Опубликованный список пакетов, который добавляют в Homebrew Channel на ТВ, чтобы ставить и обновлять приложение без ПК.
_Avoid_: репозиторий, репа, стор (в русских текстах; в именах файлов и URL используется `repo`)

**Манифест**:
Описание одной версии пакета в каталоге: версия, адрес ipk, его хэш и размер.
_Avoid_: метаданные, дескриптор

**Выпуск**:
Публикация новой версии пакета в каталоге: ipk и манифест, собранные из одной версии кода.
_Avoid_: релиз, деплой
